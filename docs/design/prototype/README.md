# Android 界面设计原型

Coolapk KMP Android 端的高保真交互原型，按 `docs/design/android-m3e-brief.md` 设计，视觉方向为 Coolapk green + Material 3 Expressive。

## 打开方式

直接用浏览器打开 `index.html`（需要联网加载 Google Fonts 的 Material Symbols Rounded 与 Noto Sans SC；离线时图标与字体会回退）。

## 内容

- 左侧目录：23 个页面/状态 + 设计系统面板。
- 顶栏控制：亮/暗主题、360/412/840 宽度、画布/总览视图。
- 画布内为原生 Android 观感：状态栏、顶栏、底部导航（宽屏切为 NavigationRail）、筛选胶囊、分段容器、弹层、Snackbar。

## 近期改版

- 动态列表：分隔线式信息流（宽屏两列），智能媒体网格（1 张通栏 / 2·4 张两列 / 3 张以上九宫格 +N），超长正文「展开全文」，扁平操作行 + 关注/更多。
- 个人主页（我的 + 酷友主页）：封面图 + 悬浮资料卡（头像压边、认证、统计三格、编辑/退出或关注/私信）+ 动态/收藏/赞过分段 Tab。

## 交互

- 首页 → 动态详情 → 评论排序 → 楼中楼 → 回复编辑 → 返回
- 数码 → 品牌/分类 → 产品列表 → 产品详情 → 图片查看
- 搜索 → 热词/分类结果 → 动态/应用/产品/用户/话题
- 发布 → 编辑 → 预览 → 发布成功返回首页
- 我的游客 → 网页登录 / Cookie 导入 → 我的已登录 → 动态/收藏/赞过 Tab → 退出确认
- 酷友主页 → 关注/私信 → 动态列表
- 消息 → 分类切换 → 带动态目标的通知 → 动态详情

返回箭头与 `Esc` 均可返回/关闭弹层。所有数据为虚构演示，发布、登录、点赞等均为原型反馈，不连接真实接口。
