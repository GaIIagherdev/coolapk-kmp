可操作的流程

  • 首页 → 动态详情 → 评论排序/只看楼主 → 楼中楼 → 回复编辑 → 返回
  • 数码 → 品牌/分类 → 产品列表 → 产品详情 → 图片查看
  • 搜索 → 热词/分类结果 → 动态/应用/产品/用户/话题
  • 发布 → 编辑 → 预览 → 发布成功返回首页
  • 我的游客 → 网页登录 / Cookie 导入 → 我的已登录 → 动态/收藏/赞过 → 退出确认
  • 酷友主页 → 封面资料卡 → 关注/私信 → 动态列表
  • 消息 → 分类切换 → 带动态目标的通知 → 动态详情
  • 发现 → 栏目/筛选 → 内容卡片 → 详情

顶栏可切换 亮/暗 与 窄/宽屏；宽屏下画布切换为 NavigationRail 与两列动态。动态列表采用智能媒体网格（1 张通栏 / 2·4 张两列 / 3 张以上九宫格 +N）与「展开全文」；个人主页为封面图 + 悬浮资料卡。返回键与 Esc 均可关闭弹层/返回上一页。
