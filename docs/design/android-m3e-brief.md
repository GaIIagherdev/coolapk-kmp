## 交付目标

为现有 Coolapk KMP 的 Android 端制作完整、精致、可交互的手机应用设计原型，以及便于 Jetpack Compose 落地的设计规范。以当前代码真实存在的页面、字段与流程为依据，所有界面使用简体中文。完成全页面覆盖，不只制作首页。

设计原型用可在浏览器查看的 HTML/CSS/JS 实现，但手机画布内部必须像原生 Android 应用。主画布按 412×915 的逻辑尺寸设计，并适配 360px 窄屏；提供 840px 及以上宽屏布局参考、亮色/暗色切换、页面总览。浏览器上的页面目录和预览控制放在画布外，不进入实际应用界面。

保留当前信息架构：首页、数码、发布、发现、我的。发布是打开编辑器的动作，不伪装成已经接入其他数据的内容频道。

## 视觉方向

原生 Android、现代数码社区、轻快而内容清晰的 Material 3 Expressive。以内容阅读和单手操作为优先。用强调字号、鲜明的主操作、可变化的控件形状、分组容器和有节制的弹性动效体现 Expressive，避免只把所有旧控件换成大圆角。

保留项目中的品牌配色起点：
- 亮色主色 #05844B，主色容器 #D1F5DF，墨色 #102019。
- 次级薄荷绿 #2E7D5B，次级容器 #B8E8CB。
- 琥珀点缀 #7B5C30，容器 #FFE1B2，用于少量评价或数码信息强调。
- 亮色背景 #F9FCF9，容器层级 #FFFFFF、#F3F8F4、#EFF5F0、#E9F0EA。
- 暗色主色 #22C875，主色容器 #173A29，背景 #101512，表面 #151D18、#19221C、#232D26。
- 状态色、文字颜色和图标对比度按语义配对，不能靠降低整个控件的不透明度表达全部状态。

字体使用 Android 风格的中文无衬线，按 Material 类型层级组织；页面标题 28–32、重要数字 32–40、模块标题 20–24、正文 14–16、辅助文字 12–14。正文不使用细字重，不把动态全文缩成小字。

形状有层级：小控件 8–12、普通卡片 16–20、主容器 24–28、主要按钮与筛选容器可用胶囊。紧邻的分组列表使用首尾大圆角、中间小圆角的分段容器，而非所有列表项都独立悬浮。内容卡片以语义色表面和留白分层，阴影轻量。

边距以 16dp 为基础，区块间距 20–24dp；触控目标至少 48dp。统一使用圆润的 Material 风格图标，不使用 emoji 充当产品图标。应用身份用原创抽象图形或文字标识，不导入官方酷安 Logo。

动画必须服务交互：选中指示器平滑移动；按钮按压具有轻微形状变化；展开与返回方向清晰；弹层有自然的进出动效；加载使用 Expressive 风格的形状变化指示器。支持减少动态效果偏好，避免持续弹跳、大幅视差和装饰性无限动画。

## 原型交互

可点击的原型必须至少完整串联：
1. 首页 → 动态详情 → 评论排序/只看楼主 → 楼中楼 → 回复编辑 → 返回首页。
2. 数码 → 品牌/分类 → 产品列表 → 产品详情 → 图片查看 → 返回原列表。
3. 搜索 → 热词或输入 → 分类结果 → 动态/应用/产品详情 → 返回保持搜索状态。
4. 发布 → 编辑 → 预览 → 保存草稿/离开确认 → 模拟发布成功返回首页。
5. 我的游客 → 登录方式选择 → 模拟登录 → 我的已登录 → 退出确认。
6. 消息入口 → 分类切换 → 带动态目标的通知 → 动态详情。
7. 发现 → 栏目/筛选 → 内容 → 详情或可辨识的外链提示。
8. 亮/暗主题、窄/宽布局和通用状态可从画布外的预览控制切换。

交互使用确定性的虚构数据。所有发布、登录、点赞与评论反馈均为原型演示，不调用真实酷安接口、不修改真实账号或发布真实内容。点击控件必须有合理反馈；画布内部不要出现 React、Kotlin、模拟接口等实现说明。

## 当前功能边界

- 已有纯文本发布；图片/视频发布未接入，因此编辑器不显示可正常工作的媒体上传按钮。
- 应用详情仅外链到酷安，不提供本客户端下载/安装按钮。
- 用户和话题搜索结果还没有完整详情页；只展示列表，若提出详情概念则必须在画布外单独标记为未来设计。
- 通知是只读列表，不提供“全部标记已读”等当前未接入的操作。
- 我的暂时只有资料与统计，不把收藏、私信、动态历史、钱包等虚构成现有功能。
- 官方登录的原生容器已存在，旧功能矩阵对 WebView 的描述有滞后；按现有 OfficialLoginScreen.kt 的实际路由设计。
- 稿件保存与发布必须呈现登录状态、账号变化保护和 1000 字限制。
- 对游客遇到详情验证失败的情况，保留列表预览或清楚的重试说明。
- 页面演示不带实际邮箱、Cookie、API Key、私有服务地址或原仓库之外的凭据。
- 只设计 Android 端。代码目录里其他未提交修改保持原样。

## 质量验收

- 全部 20 个页面/状态有清楚的目录入口，页面名称与现有功能对应。
