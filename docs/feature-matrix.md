# 功能矩阵

主界面入口为首页、数码、发布、发现、我的（iOS 为“我”）。表中的“已接入”表示存在解析、请求和界面代码路径，不等于真机或真实账号验收。

| 功能 | Android | iOS SwiftUI | 共享层与 Rust | 当前边界 |
| --- | --- | --- | --- | --- |
| 首页动态 | 原生列表；刷新、分页；首页、热榜和发现回退动态分别缓存，返回首页可恢复列表位置 | 原生列表；刷新、分页 | `HomePage`、`FeedJsonParser`；Rust 首页接口 | 只呈现可解析的动态，未覆盖首页所有卡片类型；热榜不在当前五主入口中 |
| 动态详情与评论 | 请求完整详情；评论排序、只看楼主、楼中楼、分页；评论入口定位评论区 | 进入详情后请求完整动态；失败时回退列表预览；评论排序、只看楼主、楼中楼、分页及定位 | `FeedDetailJsonParser`、`ReplyPage`；Rust 动态详情、评论及子评论接口；iOS 在 Swift 侧解析 | 游客请求完整动态可能被验证码拦截；特殊内容类型未全面适配 |
| 点赞、评论与分享 | 动态/评论点赞及取消、直接发表评论与回复评论；系统分享 | 动态点赞和直接发表评论代码路径；系统分享 | Gateway/Repository 和 Rust 互动接口 | 需要有效会话；iOS 无回复某条评论的发表入口，真实账号互动尚未验证；无站内分享 |
| 数码栏目与产品列表 | 服务端栏目、品牌/分类选择、产品列表、刷新与分页；适配窄屏和宽屏 | 服务端栏目、品牌/分类选择、产品列表、刷新与分页 | `DigitalJsonParser`；Rust 数码配置、栏目、品牌和分类接口；iOS 在 Swift 侧解析 | 部分特殊卡片或网页栏目不能作为原生列表展示 |
| 数码产品详情 | 独立详情页，展示图片、品牌/分类、评分、热度、介绍和规格等已解析字段 | 详情弹层，展示图片、规格、价格、评分、上市等已解析字段 | `DigitalProductDetailJsonParser` 与 Rust 产品详情接口；iOS 解析产品实体 | 字段取决于服务端响应；两端详情展示范围不同 |
| 纯文本发布与草稿 | 编辑/预览、字数限制、按账号保存/恢复草稿；会话变化时阻止旧账号发布 | 编辑/预览、字数限制、按账号保存/恢复草稿 | Rust 普通动态发布接口 | 不支持图片、视频等媒体发布；发布需登录，可能遇验证码或风控；真实账号发布未验证 |
| 多类型搜索 | 综合、应用、游戏、用户、动态、问答、数码、话题；热词、分页；问答子筛选；按分类保存结果 | 同八类搜索、热词与分页 | `SearchJsonParser`、Rust 分类型搜索接口；iOS 在 Swift 侧解析 | 动态、应用和数码结果有对应详情入口；用户、话题等结果没有完整详情页 |
| 发现 | 服务端栏目、内容卡片和站内/网页跳转；筛选项可切换数据源；分栏目缓存、恢复滚动位置和分页 | 服务端栏目、内容卡片和站内/网页跳转；刷新与分页 | `DiscoveryJsonParser`、配置及栏目接口；iOS 在 Swift 侧解析 | Android 筛选已接入，iOS 筛选项仅展示；特殊卡片未全部原生适配，配置失败时回退科技快讯 |
| 图片查看 | 从动态、应用截图及数码产品图片等入口打开全屏查看器 | 从动态图片和应用截图等入口打开全屏查看器 | 图片地址由各解析器提供 | 仅覆盖已接入图片入口，非完整媒体浏览器 |
| 应用 | 搜索及相关卡片可进入原生详情；工程保留应用列表逻辑 | 搜索及相关卡片可进入原生详情；工程保留应用列表页面代码 | `AppJsonParser`、`AppDetailJsonParser`；Rust 应用列表与详情接口 | 应用不是当前主入口；工具/社交列表为关键词搜索，不是官方分类榜单；不负责下载或安装 |
| 我的与通知 | 资料、统计、退出登录；未读数和五类只读通知，可从含动态目标的通知打开详情 | 资料、统计及退出登录代码路径；未读数和五类只读通知，动态入口请求详情 | 用户资料、通知数量和列表接口 | 无完整个人内容列表；通知不能标记已读；iOS 账号路径待真实凭据验证 |
| 官方网页登录与会话 | 官方登录 WebView 自动读取原生 Cookie，授权码优先、Cookie 校验回退；保留手动导入；Keystore AES-GCM 加密存储 | 独立 WKWebView 自动读取原生 Cookie，授权码优先、Cookie 校验回退；保留手动导入；Keychain 存储 | Rust 授权码兑换、会话校验及失败回滚；UniFFI 登录入口 | 两端仅实测官方网页加载，未用真实账号验收回跳、验证码、风控及会话恢复；系统浏览器或官方 App 的会话不会自动导入 |
| 平台桥接 | KMP `androidMain` Gateway -> UniFFI Kotlin/JNA -> Rust `.so` | SwiftUI -> UniFFI Swift -> Rust XCFramework | `shared/iosMain` 的 `createPlatformGateway()` 仍占位 | iOS 未通过 KMP Gateway 获取真实数据；XCFramework 含模拟器/设备静态库 |

Android 主题使用 Coolapk green 和 Material 3 Expressive；iOS 使用 SwiftUI 原生控件与绿色强调色。Android 单元测试和 Debug 构建已通过，并在 Pixel 9 Pro XL 模拟器看到真实首页、热词/搜索结果、数码品牌列表、产品详情及官方登录页；取消网页登录后仍为游客态。iOS arm64 模拟器构建及纯 Foundation 解析测试通过，已在模拟器看到首页真实动态、图片和官方登录页。两端真实账号授权回跳、登录后交互、发布和会话恢复尚未逐项验证。
